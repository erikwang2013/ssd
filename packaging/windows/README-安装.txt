小盾 (xiaodun) — Windows x64 便携版
===================================

【启动】
  双击 xiaodun.exe 启动界面。引擎进程 xd-daemon.exe 必须留在同一目录
  （界面按「与主程序同目录」自动发现它；也可用环境变量 XD_DAEMON_BIN 指定别处）。

【权限说明（重要）】
  Windows 物理磁盘的枚举/读取需要管理员权限：普通权限启动时首页会显示「未发现设备」，
  并给出「以管理员身份重启引擎」按钮——点击后弹出 UAC 对话框，授权即以管理员权限重启
  引擎进程并重新列出设备；取消/超时会给出原因，可重试。**真机 UAC 交互未验证**（CI 无
  桌面/无交互会话），细节见 docs/security/linux-privilege-model.md §10/§13。
  其他可用方式：
    1. 或先用镜像文件体验完整流程：把 .img 路径设到环境变量 XD_IMAGE 后启动；
    2. 或右键 xiaodun.exe →「以管理员身份运行」（该路径未在真机验证）；
    3. 或命令行手动验证引擎（界面不连接既有实例：它总是自行拉起同目录的
       xd-daemon.exe；手动实例仅供命令行验证）：
         xd-daemon.exe --device \\.\PhysicalDrive1

【依赖】
  Microsoft Visual C++ 运行库（VS 2015-2022 x64）。绝大多数系统已自带。

【只读承诺与同盘校验】
  扫描/预览全程对源介质只读；恢复导出必须另选目标目录。注意：Windows 的
  「目标盘是否与源设备同盘」校验尚未生效（M2 补），请自行避免把恢复结果写回源盘。

【未签名】
  本版本未做代码签名，Windows SmartScreen 可能提示 → 选择「仍要运行」。
